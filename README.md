# MiniZone Web Start

MiniZone 在 Mos 2.0 替代前的单文件 Web 前端整理版，用于阅读、研究和后续迁移。

这里保留了 `index.html`、应用图标、品牌图片及活动背景，来源为 MiniZone 原工作区保存的 Mos 2.0 替代前单文件前端。历史页面中的模块版本标记不能代表整个站点的正式发布版本；本目录尚未与替代前的线上文件逐字节比对，因此不能认定为历史线上最后一次发布的逐字节版本。

## 本地查看

需要 Node.js 20 或更高版本，无第三方运行依赖，无需安装 npm 包。

```sh
npm run check
npm run preview
```

打开 <http://127.0.0.1:8092/>。也可以用 `node scripts/preview.cjs 8092` 指定端口，或访问同一服务的 `/stu/` 路径检查历史子路径布局。

预览只提供本目录的页面和静态图片，所有 `/api/` 与 `/stu/api/` 请求均返回说明性错误；它不会代理线上接口，也不模拟成功登录、发帖、支付或其它业务操作。界面可以查看，实际数据与交互需要匹配的历史后端。切勿输入真实账号或支付信息。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 历史页面、样式和脚本；本次整理保留原文件 |
| `assets/brand/` | MiniZone 品牌资源及其原始使用说明 |
| `app-icons/` | 应用图标的 SVG 与 PNG |
| `favicon.png`、`activity-background.png` | 页面静态图片 |
| `scripts/` | 本次补充的本地预览与检查工具 |

## 接口与部署边界

页面调用同源 API，在 `/stu/` 下运行时自动采用 `/stu/api/...`，其余情况使用 `/api/...`。前端使用浏览器存储保存登录状态和偏好，登录令牌由后端返回；本项目不附带预置会话。

本目录不包含历史后端、数据库、上传文件或私密配置，未验证当前 Mos2 后端能完整兼容此页面。要恢复完整服务，应先核对历史 API 契约、鉴权与资金流程，并在独立数据目录中验收。单纯将静态页面放到服务器不能恢复完整历史站点。

## 发布前检查

```sh
npm run check
npm run check:release
```

第一条核对页面脚本语法、本地引用、受限文件与常见凭据模式。第二条还要求项目许可证及素材授权状态已落实。检查结果只代表这些机械检查，不能替代完整的安全审计与素材权利核对。
